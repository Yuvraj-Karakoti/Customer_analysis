# 🛍️ Customer Shopping Behaviour Analysis

An end-to-end data analytics project analyzing customer shopping behavior using **Python, SQL Server, and Power BI**.

The project covers the complete analytics workflow, from raw data cleaning and transformation to SQL-based business analysis and Power BI visualization.

---

## 📌 Project Overview

The objective of this project is to analyze customer shopping behavior and identify patterns in:

- Customer spending
- Revenue by gender
- Discounts
- Product ratings
- Shipping preferences
- Subscription behavior
- Customer loyalty
- Product popularity
- Age-group revenue contribution

The project follows an end-to-end analytics workflow:

**Raw CSV Data → Python → SQL Server → SQL Analysis → Power BI → Business Insights**
